ABOUT THIS PROTOTYPE

A local-first exhibition experience.

This two-layer web prototype demonstrates how structured exhibition data can become an interactive digital experience that remains functional without runtime internet access.

01

Layer 1

Landing page with exhibition overview, theme navigation, statistics and visitor-journey framing.

02

Layer 2

Theme exploration and individual exhibit details with useful search and interaction.

03

Offline

Data and assets are local, enabling the web experience to be bundled into a Windows application later.

04

Packaging

The same web layer can be wrapped with Electron or Tauri for desktop distribution.
